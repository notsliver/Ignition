# Ignition

A simpler way to deploy.

## Repository layout

| Path | Description |
| --- | --- |
| [`apps/web`](apps/web) | Web app: React + Vite, with the in-house UI library in `src/ui` |

## Getting started

```sh
cd apps/web
npm install
npm run dev
```

See [apps/web/README.md](apps/web/README.md) for details.

## Contributing

Project conventions live in [AGENTS.md](AGENTS.md):

- Use Heroicons (`@heroicons/react`) for all icons.
- Keep the restrained visual style and compact UI scale.
- Provide reduced-motion alternatives for every animation.
