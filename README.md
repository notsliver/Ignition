# IGNITION

Built with React, Vite, and Heroicons.

Run `npm install` and `npm run dev` to develop. Use `npm run build` for a production build, and `npm run preview` to inspect it.

The content area is a coming-soon placeholder. Navigation, collapsible groups, compact mode, keyboard search (Ctrl/Cmd+K), project and environment selection, and quick-create previews are interactive. Select Projects, then Explore a project, to enter project navigation.

Quick-create forms and resource counts are illustrative. They do not create or deploy infrastructure. The preview details dialog contains the sample Blueprint resource table; creation previews include Blueprint date selection. Motion respects the system reduced-motion preference.
